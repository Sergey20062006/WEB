# Практична робота: РОЗРОБКА КЛІЄНТ-СЕРВЕРНИХ ВЕБ-ДОДАТКІВ

**Тема:** Node.js, Express, REST API, Асинхронний JavaScript

**Варіант 9:** Облік трансформаторних підстанцій (ТП) житла

## Про проєкт
Цей проєкт являє собою повноцінний клієнт-серверний веб-додаток для реєстрації, моніторингу та обліку трансформаторних підстанцій житлового фонду. Мета роботи — демонстрація навичок створення серверної частини (backend) за допомогою Node.js, розробки RESTful API, роботи з файловою системою та реалізації асинхронного обміну даними між клієнтом і сервером без перезавантаження сторінки.

## Основний функціонал
* **Реєстрація об'єктів (POST):** збір даних через валідовану HTML-форму (адреса, тип, кількість квартир, потужність, навантаження, стан) та їх збереження на сервері.
* **Динамічне відображення (GET):** автоматичне завантаження та генерація карток підстанцій на основі даних із сервера.
* **Кольорова індикація станів:** візуальне підсвічування карток залежно від технічного стану ТП (зелений — справна, жовтий — в ремонті, червоний — потребує ремонту).
* **Видалення записів (DELETE):** можливість видаляти підстанції з бази даних із попереднім підтвердженням дії.
* **Живий пошук та фільтрація:** миттєвий пошук за адресою та фільтрація за технічним станом на стороні сервера (реалізовано додаткове завдання).
* **Експорт даних (CSV):** можливість вивантажити всю базу підстанцій у форматі CSV для подальшого аналізу в Microsoft Excel (реалізовано додаткове завдання).

## Технологічний стек
* **Frontend (Клієнтська частина):**
  * **HTML5:** семантична розмітка, вбудована валідація форм.
  * **CSS3:** стилізація, адаптивний дизайн за допомогою CSS Grid та Flexbox.
  * **JavaScript (ES6+):** клієнтська логіка, маніпуляції з DOM, `Fetch API` для асинхронних запитів.
* **Backend (Серверна частина):**
  * **Node.js:** середовище виконання серверного коду.
  * **Express.js:** фреймворк для створення веб-сервера та обробки маршрутів (Routing).
  * **File System (fs):** збереження бази даних у локальному файлі формату `JSON`.
  * **json2csv:** NPM-модуль для конвертації JSON-даних у табличний формат CSV.
